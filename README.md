# Moscow Bus Tracker (Mos.ru)

Интеграция для отображения расписания автобусов Москвы на основе официального API Портала открытых данных (Mos.ru) с поддержкой OData-фильтрации и GTFS-календарей.

## Особенности
* Многошаговая настройка через UI (ввод токена, поиск маршрута, выбор остановки).
* Автоматическая генерация ссылок на Яндекс.Карты для точного выбора стороны дороги.
* Корректная обработка ночных маршрутов (автоматический перевод времени 24:15 -> 00:15).
* Оптимальное кэширование запросов на базе `DataUpdateCoordinator`.

## Установка через HACS
1. Перейдите в **HACS** -> **Интеграции**.
2. В правом верхнем углу нажмите три точки -> **Пользовательские репозитории** (Custom Repositories).
3. Вставьте ссылку на этот репозиторий GitHub.
4. В поле "Категория" выберите **Интеграция** и нажмите **Добавить**.
5. Найдите `Moscow Bus Tracker` в поиске HACS и нажмите **Скачать**.
6. Перезапустите Home Assistant.
